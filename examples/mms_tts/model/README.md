# Model provenance

[简体中文](README_CN.md) | English

English MMS-TTS encoder and decoder from Rockchip `rknn_model_zoo/examples/mms_tts`, converted for RV1126B. The ONNX source models and ready-to-run RKNN files are kept together. Checksums are recorded in `SHA256SUMS`.

Input is English ASCII text with a maximum length of 99 characters. Output is 16 kHz mono PCM audio. Verify redistribution terms of the upstream `facebook/mms-tts-eng` model before publishing model binaries.
